# AST10202 GitHub Onboarding

Complete this exercise to register your GitHub account and practice the basic Git workflow:

1. Create a GitHub account.
2. Fork this repository.
3. Clone your fork to your computer.
4. Create your own folder inside `students/`.
5. Add a file named `profile.txt`.
6. Commit and push your change.
7. Open a pull request to this repository.

## Required file format

Create this file:

students/YOUR-GITHUB-USERNAME/profile.txt

Replace the placeholders with your information:

Name: Your name
GitHub username: YOUR-GITHUB-USERNAME
GitHub profile: https://github.com/YOUR-GITHUB-USERNAME

Do not edit or delete another student's folder or file.
